# Splash pipeline test

This is a synthetic, self-contained reporting package for an end-to-end Splash
test. No figure, person, organisation, or quotation in this folder is real.

Use these as the intake inputs:

- `article.md` — draft article
- `data.csv` — complete source table

Use these as supporting context before framing the story:

- `context.md` — editorial intent, verified calculations, and constraints
- `text.txt` — synthetic interview transcript

The intended test is to let Splash infer and rank visual approaches from the
editorial intent. The files deliberately do not prescribe a chart type.
