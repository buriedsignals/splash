# The typeface this story draws in

`proposeTypeface({ newsroom, resolves: familyResolves, sample })` was run with this beat's own
strings — the title, the year labels, the values `106 237`, `104 442` and `150`, and the source
line — not a Latin probe.

Space Grotesk is the house face and this machine does not have it: the probe produced identical ink
in that family and in a nonsense one, which is what a silent fallback looks like from outside.
Courier New resolves here and was offered, not recommended — a monospaced typewriter face sets a
chart's own numbers on a code grid, and this beat's numbers are the argument.

Recorded, on the proposal's own recommendation, is the substrate's stack, as a choice with the gap
named. `origin: default` is the honest word: nobody chose this face.

**One thing this measurement does not cover, said here rather than assumed.** `familyResolves` is
`chart-beat`'s resvg-based probe, and this beat renders through Remotion, i.e. headless Chrome.
Both read the same operating-system font list, so the answer is the same one; but the probe that
produced it was not run against the engine that will draw it.
