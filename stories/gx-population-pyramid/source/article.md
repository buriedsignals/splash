# Les femmes passent devant les hommes à partir de 60-64 ans

En Suisse, les hommes sont plus nombreux que les femmes dans toutes les bandes d’âge jusqu’à 55-59 ans. À partir de 60-64 ans, la tendance s’inverse et les femmes sont majoritaires dans chaque bande, jusqu’aux centenaires.

Source : ONU, World Population Prospects (2024), via Our World in Data.
