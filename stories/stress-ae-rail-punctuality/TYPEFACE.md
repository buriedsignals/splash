# The typeface this story draws in

`proposeTypeface({ newsroom, resolves: familyResolves, sample })` was run with this beat's own
strings — the panel labels, the years, the values and the source line — not a Latin probe.

Space Grotesk is the house face and this machine does not have it: the probe produced identical ink
in that family and in a nonsense one, which is what a silent fallback looks like from outside.
Courier New resolves here and was offered, not recommended — a monospaced typewriter face sets a
chart's own numbers on a code grid.

Recorded, on the proposal's own recommendation, is the substrate's stack, as a choice with the gap
named. `origin: default` is the honest word: nobody chose this face. Until Space Grotesk is
installed on the machine that renders, this beat is not set in the newsroom's own type, and this
file is where that is said rather than hidden in a renderer literal.
