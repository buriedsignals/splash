# World GeoJSON

`world.geojson` — Natural Earth admin-0 countries, 1:50m scale.

Source: https://d2ad6b4ur7yvpq.cloudfront.net/naturalearth-3.3.0/ne_50m_admin_0_countries.geojson

Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.

ISO-3166 alpha-3 country code is in the `iso_a3` property on each feature.
