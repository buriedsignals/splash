Four ways in

You already have the thing it needs. Say so.

Four openings, and each one is a sentence you type. Nothing below is a menu item — it is what was actually written into the assistant at the top of the session.

  1. 01
    From a filed story Read this draft and the CSV next to it. Which claims can we actually show?

    The piece is written and the numbers sit beside it. Splash reads both and tells you which claims the data carries visually — and which ones it does not.

  2. 02
    From a dataset Profile this file. Tell me what it supports, and what would be a stretch.

    The numbers arrived before the angle. The file is profiled first — shape, gaps, units, what it does not measure — and only then is anything proposed.

  3. 03
    From a published piece Section three is the whole story. Rebuild it for a phone.

    It ran as text and it deserved better. Point at the section that carries the argument; it comes back as the form that argument needs.

  4. 04
    From a live feed Build this as a standing graphic. It has to re-render when the endpoint updates.

    The number changes after you publish. The graphic is written as a program, so it re-renders against the feed instead of being redrawn by hand every week.

Splash

Splash is an open skill pack that gives any newsroom a visual desk — the AI you already use, taught to build scrollytelling maps, chart stories, interactive graphics and motion video. Open source, key-free to try, and ready for any CMS.
