# The type survey's proven-formats column is owed a rebuild — 2026-09-17

`bun run survey:check` fails on committed `main`. This note says exactly what is drifted, why
regenerating alone would replace one false statement with another, and what is owed.

## What is drifted

`skills/storyboard/references/type-survey.md` is generated by `bun scripts/type-survey.mjs` from
the 40 type sheets plus `readBeats()`. Its **proven formats** column is a coverage fact: which
formats have an artifact on disk under `proof/` for that type. Around 85 beats moved to
`archive/` and the corpus settled at 160, and the file was never regenerated, so today it claims
coverage the tree no longer carries — image types in particular are listed as proven while every
image beat now lives under `archive/`.

`bun run catalog:check` and `bun run matrix:check` are green; this is the survey alone. The
purpose column is not involved — the `**Argues:**` lead-line defect that drifted the visual
catalogue's six treatment purposes is fixed in `scripts/type-survey.mjs`.

## Why `bun scripts/type-survey.mjs` is not the whole answer

Regenerating makes most rows truer and one row falser. `provenFormats` joins a sheet to a beat by
comparing word tokens, and three beats declare a type no sheet answers to:

    proof/static-slope-europe-lowcarbon/BRIEF.md    **Type:** slope chart (two dated rails)
    proof/scrolly-slope-europe-lowcarbon/BRIEF.md   **Type:** slope chart (two dated rails)
    proof/video-slope-europe-lowcarbon/BRIEF.md     **Type:** slope chart (two dated rails)

The sheet is `Slope (slopegraph)`, whose aliases are `slope` and `slope slopegraph`; `slope chart`
matches neither. `proof/web-slope-europe-lowcarbon/BRIEF.md` writes `slope` and does match. So a
regeneration today would print **slope: web** for a type this corpus proves on all four formats —
a coverage claim a journalist reads, and wrong.

Measured: `readBeats()` returns 160 beats, of which exactly 3 declare a type no sheet claims, and
`slope chart` is the only such value.

## What is owed

1. Normalise the three `**Type:**` lines to `slope`, the spelling the fourth export and the sheet
   already use. Beat prose, three files.
2. `bun scripts/matrix.mjs` and `bun scripts/type-survey.mjs`, then `matrix:check` and
   `survey:check`.
3. Re-read the regenerated proven-formats column against `MATRIX.md` before committing it: any
   other row that loses a format is either a real archive move or a second alias miss, and the two
   read identically from here.

Loosening the alias join instead — substring matching, or dropping a trailing `chart` — is the
tempting one-line version and is the wrong one: the join is token-exact so that a beat declaring a
type nobody wrote a sheet for fails loudly rather than being silently absorbed into a neighbour.

## Why it is recorded rather than done

It was found while fixing four unrelated failures and the catalogue's own drift; it is corpus
work with a judgement call in step 3, not a test fix. `skills/storyboard/test/type-survey.test.ts`
("should regenerate byte-identically from the tree") is red on `main` and stays red until this is
done — it lives in the heavy lane, which is why `bun run test` does not show it.
