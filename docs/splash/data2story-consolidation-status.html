The decision

One Splash repository and one Splash pipeline

The former rd-dev doctrine-twin tree was intentionally promoted as the product baseline rather than merged as if the unrelated histories shared ancestry. New work continues from current main; nobody needs to recover or merge the historical branch to implement the PRD.

What stays authoritative

  • Splash's journalist-owned story directory and file-backed state
  • The tuned Splash visual doctrine, front end, and craft skills
  • Confirmed takeaway, real-draft review, approval, and chosen delivery gates
  • Agent judgment informed by ranked visualization knowledge

What the PRD adds

  • Reusable evidence packages with provenance and limitations
  • Explicit reproducible findings and semantic claim support
  • An editable, versioned production plan with several possible outputs
  • Traceable handoffs and per-output review state

Current production line

The existing workflow remains the backbone

Current production is already human-gated end to end. The PRD expands the records around evidence and planning; it does not replace the craft layer or turn Splash into an article generator.

What landed and what remains

Landed on main

  • Consolidated doctrine-twin product baseline and current README
  • Stable story/output identity and contained export destinations
  • Approval and QA bound to render digest, plan version, and finding IDs
  • Journaled local replacement with crash recovery
  • Bounded Cloudflare delivery and ambiguous-result reconciliation
  • One shared ~/.agents/skills store for Goose, Codex, and Gemini

Still in the active PRD

  • Atomic evidence package and source/calculation provenance
  • Optional, consented external context acquisition
  • Semantic per-claim grounding and compact angle/evidence brief
  • Canonical versioned production plan and recovery from that plan
  • Multi-output derivatives, packaged topology, and handoff adapters
  • Journalist/editor pilot and credential-gated live MapTiler verification

Non-negotiable boundaries

Traceability supports judgment; it does not replace it

Evidence links are not truth certificates. A resolved source or calculation can show where a claim came from. It cannot by itself establish fair framing, factual completeness, visual honesty, or fitness to publish. Those remain explicit journalist and editor decisions.
