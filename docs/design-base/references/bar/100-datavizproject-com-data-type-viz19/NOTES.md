## What it is

The same three-country dataset, drawn as a 2004 marker and a 2022 marker per row with the span
between them filled.

## What it does with information

**The derived quantity is what is printed, not the endpoints.** Inside each ribbon, in white:
`+150%`, `+60%`, `+15%`. The two raw values are shown only as positions against the scale; the
number the chart hands the reader is the one the comparison is about. Checked against the axis
positions: Denmark 4 → 10 is +150 %, Norway 5 → 8 is +60 %, Sweden 13 → 15 is +15 %. The arithmetic
holds.

**And the rows are ordered by that derived quantity** — DK, NO, SE, descending by change — not by
either endpoint. Sweden, the largest country on both dates, sits at the bottom because the chart's
subject is growth. The ordering states the argument before a single number is read.

**The scale survives because the endpoints still need one.** Unlike #6 and #24, this chart keeps a
0–15 axis with vertical rules, because the positions carry information the printed labels do not.

## What it does with style

Ground `#F4F7F7` at **44.9 %**, `#FFFFFF` at **44.2 %**; strongest chromatic cluster `#3274DA` at
**8.6 %** — again largely DVP's navigation bar, which cannot be separated from the chart's own blue.
Palette read as **sequential**. The ribbon is a blue-to-red gradient between the two markers, which
is decoration: it implies a continuous path between two census dates that were never continuous.

## What is transferable

- **Print the change, not the two values, when the change is the subject.**
- **Order the rows by the quantity the chart is about**, even when that demotes the largest row.
- **Keep the axis when position still carries information** the labels do not.

## What is this piece's own

The diamond markers, and the gradient between them — which asserts a path the data does not have.

## What was not verified

The chart's own typography, unmeasured for the same reason as every DVP record. The exact endpoint
values were read off the axis by eye, not from a data table; they are consistent with #6 and #23,
which print them. One publication.
