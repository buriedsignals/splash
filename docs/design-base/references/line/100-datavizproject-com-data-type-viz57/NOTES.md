# 100 datavizproject — #57, paired arcs with an identity mark

- url: https://100.datavizproject.com/data-type/viz57/
- archive: datavizproject
- type: paired arcs (donut), one per entity
- export: static
- readAs: the encoding as the page draws it, read at rest

## What it is

Three rings, one per country, each carrying two arcs — the 2022 value in the country's own colour
and the 2004 value in grey — with the national flag set inside the ring.

## What it does with information

**The comparison sits in one ring.** The earlier value is drawn as a grey arc concentric with the
coloured one, so the gap between the two arc ends *is* the change. Same move as #12, in a different
geometry.

**The past is neutral and the present is accented.** Grey for 2004, hue for 2022. That is the
colour grammar this repository already holds — neutral carries history, the accent carries the
subject — arrived at independently.

**Identity is carried by an icon inside the mark**, not by a label beside it: the flag says which
country without a word.

## What it does with style

The only one of the five whose palette the pixel route reads as **sequential** rather than
diverging, because the greyed past withdraws from the hue set entirely — a measurable consequence
of the neutral/accent split.

## What the pixel route actually measured here

`largestGraphic` returned this site's own wordmark — `logo-100.svg`, 280 x 80 at (80, 0) — which is
too small to photograph, so the pixel route fell back to the **whole page**. The ground and the
chromatic colours in this record are therefore the SITE's, not this encoding's: `#3274DA` at
8.6-10.5 % is Ferdio's fixed navigation bar, and it happens to be the same blue the charts are drawn
in, which is exactly why it read as plausible. Nothing in this note rests on that reading, and no
direction may be measured from this record.

## What is transferable

- **Draw the earlier value in neutral, concentric with the accented current one**, so the change is
  a gap rather than a second mark.
- **An identity icon inside the mark** removes a label without removing the identity, wherever the
  entities have a recognised mark of their own.

## What is this piece's own

The flags, which only work for countries; the donut geometry.

## What was not verified

Whether the arcs are on a common scale across the three rings — if they are not, the between-country
comparison the layout invites would be false.
