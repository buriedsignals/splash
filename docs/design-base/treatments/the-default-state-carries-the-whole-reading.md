## The rule

A reader who touches nothing must still get the argument. Interaction adds the detail a frame could
not hold — never the reading itself.

## The evidence, and why this pair is the strongest kind

**Two publications in two different families** — a boxplot and a ranking — which is what makes this a
rule about the EXPORT rather than about a chart type.

**NSIDC**, sea-ice tool: *"nothing is hidden behind the interaction. The default state already
carries median, both bands, the current year and the record year; the eighty-odd checkboxes ADD
years, they do not reveal the chart."*

**Information is Beautiful**, LLM ranking: *"every point is labelled directly. There is no hover-only
identity — each model's name is set beside its dot in the producer's colour. Identity never depends
on the legend."*

## The honest limit, from the same record

That IiB piece's top cluster **is** illegible at rest, and the piece answers it *"with the search
field rather than by pretending otherwise"*. So interaction may solve a density the frame genuinely
cannot hold. It may not hold the argument.

this corpus existed, and reached the same rule from the other direction: *"the honest use of
interaction here is detail the static frame had to omit, never the same numbers repeated on
