## The rule

Put a dot where the source put the thing. Nowhere else.

## The evidence

**La Nación** states the reasoning outright: *"the dots sit on the **streets** rather than in
polygons, so the pattern reads as 'along this avenue' rather than 'in this neighbourhood' — a choice
about what the data can honestly support, **since a crime has a street address and not an area**."*

**ProPublica**, Louisiana: the same rule met from a different source — *"each point represents a
facility"*, and a facility has coordinates.

## It is a refusal as much as an instruction

A dot-density map made by scattering national totals inside national polygons draws a texture the
source cannot support: **the pattern a reader sees is the scatter's, not the world's.** Every cluster
is an artefact of the random number generator and every hole is one too.

This base's first attempt at this family was exactly that — one dot per terawatt-hour, thrown inside
a country's outline — and this treatment is the reason it was not built. What was built instead uses
a source that records a latitude and a longitude for every thing it counts.

## Its relation to the unit rule

`a-quantity-is-made-countable-by-drawing-its-units` asks that one mark be one real thing. This asks
that the mark be in the right place. A dot map satisfying only the first is a pictogram wearing a
basemap; satisfying only the second is possible and is a different form — a proportional symbol map,
where the mark stands for a quantity at a place rather than for a thing.
