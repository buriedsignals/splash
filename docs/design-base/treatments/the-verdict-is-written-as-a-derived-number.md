# the-verdict-is-written-as-a-derived-number

- kind: imported
- name: The number the reader would work out — the gap, the remainder, the change — is printed
- applies: every mark the beat draws carries a comparative state to be measured against
- draws: value
- priority: 9
- evidence: bbc-co-uk-news-election-2024-uk-results
- evidence: icaew-com-insights-viewpoints-on-the-news-2025-jun-2025-chart-of-the-w
- detect: the delivered artifact prints, per row, the difference between the measure and its
  comparative state

## The rule

Print the subtraction. The plate has already done it.

## The two publications

The BBC prints `0 seats to go` beside its majority line — this base's record: *"what a reader wants
and what a bullet leaves them to compute."* ICAEW draws the SHORTFALL as a labelled area instead of a
target tick, because *"a target tick answers it only after a subtraction the reader performs by eye
against an axis."*

## Why the predicate is strict

It fires only where EVERY mark has a comparative state. A verdict printed on some rows and not others
is a plate that looks complete and is not: the reader cannot tell a row with no gap from a row whose
gap was not computed.

## Its companion refusal, from ICAEW

**Let a met target disappear.** A zero-height shortfall, or a tick sitting behind the bar's own end,
costs ink to say nothing; omitting it says *already passed* for free — provided the reader has a
second column to compare against, which `the-verdict-is-written-as-a-derived-number` supplies.
