Documentation

How Splash works

Splash is a skill pack, not a hosted application. You run it through the AI assistant already on your desk, and it turns reporting material into charts, maps, scrollytelling and video — stopping at editorial gates instead of publishing on your behalf. Everything it makes stays in a directory you own.

01 — What it is

A visual desk your agent runs

Most newsrooms know a story would land better as a chart or a map. What they lack is a graphics desk with the time to build one. Splash is seventeen skills that teach an AI assistant that craft — how to read your evidence, propose a form that the data actually supports, draw it for real, and hand you something a CMS will take.

It is local-first by design. Stories and newsroom configuration live outside the replaceable Splash checkout, credentials stay in the operating system's protected store through Engine, and every delivery is a file or a directory the newsroom controls. Nothing is uploaded to run it.

Why the gates are hard stops

Craft-skill selection is ranked, but a ranking is a suggestion. The journalist's confirmed takeaway always wins, and Splash refuses to treat an unapproved storyboard as settled. If your data will not support the form you asked for, it says so at the storyboard rather than drawing something the evidence does not carry.

04 — Formats

The same story in four formats

A beat is built once. The format decides how it leaves, and each route carries only the delivery forms it can actually honour.

RouteWhat it isDelivery

Forty-four forms sit behind those routes — charts, maps and scrollies. Splash knows what each one needs, and says so when your data will not support the one you asked for.

05 — Story directory

Everything lands in a folder you own

Splash does not hold your work. Source files, editorial decisions, rendered drafts, approvals and delivery artifacts all sit in a journalist-owned story directory, outside the Splash checkout — so you can replace or delete Splash without losing a story.

stories/<your-story>/
  source/          the frozen article and data, never edited in place
  STORYBOARD.md    the angle, the forms, and what you approved
  beats/           one directory per beat, with its rendering code
  renders/         the real output, versioned per approval round
  delivery/        what you hand to the CMS
06 — Install

Two ways to get it

Managed — recommended

Indicator Labs on Mac or Windows, with guided setup, credential management, repair and automatic updates. Join at buriedsignals.com/join →

Agent-led manual install

The same Engine, through its public signed standalone release. Fetch the bootstrap JSON for your platform, verify both the SHA-256 and the Minisign signature before extracting or executing bsig, then sync the catalog.

https://navigator.indicator.media/api/artifacts/bootstrap/bsig/<platform>
# darwin-arm64 · darwin-amd64 · linux-arm64 · linux-amd64 · windows-amd64

bsig catalog sync
bsig plan install splash

Windows 11 amd64 is a prepared host: Engine does not install Goose Desktop, Git, Bun, Docker or Node, and anything missing fails at plan time. Review the emitted plan, apply that exact plan.json, and launch Goose from the Start menu once doctor is green. Do not run install.sh on Windows.

07 — FAQ

Common questions

Does Splash publish anything on my behalf?

No. It stops at the delivery decision and hands you files, a CMS package or a hosted page. Nothing leaves your machine unless you send it.

Do I need an API key to try it?

No. Splash is key-free to try. Credentials, where a route needs them, are held in your operating system's protected store through Engine rather than in a config file.

Which assistant does it run in?

Whichever one your desk already uses — it is a skill pack, not an app. The managed install sets up Goose; the manual path works with any runtime that reads the skill format.

What if the data does not support the chart I want?

Splash tells you at the storyboard, before anything is drawn, and proposes the forms your evidence does carry. The ranking is a suggestion; your confirmed takeaway wins.

Can I re-open one beat without rebuilding the story?

Yes — that is the revision loop in the diagram above. Editor feedback reopens a single beat, re-renders it and re-delivers, leaving the rest of the story untouched.
